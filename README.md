
Student Management System

About
This is a beginner-friendly Student Management System built with Python and Flask.

Features
- Add a student
- Enter student name and student ID
- Display the student list

 Technologies Used
- Python
- Flask
- HTML

 Requirements
Python 3 and Flask are required to run this project.

How to Run
1. Install Python 3.
2. Install Flask using:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000
